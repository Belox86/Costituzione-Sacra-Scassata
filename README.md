## 📝 Come è scritto la costituzione: Il linguaggio Markdown (`.md`)

Il testo della costituzione è contenuto nel file `index.md` ed è scritto in **Markdown**, un formato di testo puro facilissimo da leggere ed editare. Non servono programmi complessi: gli stili grafici (titoli, elenchi, grassetti) si applicano usando semplici simboli di testo.

### 📚 Guida rapida alla sintassi Markdown

Se vuoi aggiungere o modificare del testo, ecco la sintassi di base da utilizzare:

* **Titolo principale (Grande):** `# TITOLO I – COMPOSIZIONE`
* **Sottotitolo (Medio):** `## Capo I: Sistema di Punteggio`
* **Sezione (Piccolo):** `### Regola speciale`
* **Grassetto:** `**Testo in grassetto**`
* **Corsivo:** `*Testo in corsivo*`
* **Elenco puntato:** Usare il trattino `- ` oppure l'asterisco `* ` seguito da uno spazio all'inizio della riga:
  ```markdown
  * Primo punto
  * Secondo punto
  ```
* **Elenco numerato:** Usare il numero seguito dal punto `1. `:
  ```markdown
  1. Prima regola
  2. Seconda regola
  ```
* **Note o citazioni:** Usare il simbolo `> ` all'inizio della riga:
  ```markdown
  > Così deciso in Brescia, addì 25 giugno 2011.
  ```
* **Linea divisoria orizzontale:** Inserire tre trattini `---` su una riga vuota.

Per approfondire, puoi consultare la [Guida Ufficiale al Markdown di GitHub](https://docs.github.com/it/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax).

## 🛠️ Come modificare o aggiungere una regola

Non serve usare il terminale né installare software sul computer. Puoi fare tutto direttamente dal browser in pochi semplici passaggi:

### Metodo 1: Modifica rapida dal browser (Consigliato)

1. **Apri il file del regolamento:**
   Clicca sul file [`index.md`](index.md) nell'elenco dei file in alto.

2. **Attiva la modalità modifica:**
   In alto a destra sopra il testo, clicca sull'icona della **matita** (*Edit this file*).

3. **Modifica e salva:**
   * Fai le tue modifiche al testo seguendo la sintassi Markdown mostrata sopra.
   * Quando hai finito, clicca sul pulsante verde in alto a destra **"Commit changes..."**.
   * Lascia selezionata l'opzione *"Commit directly to the `main` branch"*.
   * Clicca nuovamente sul pulsante verde di conferma per salvare.

🎉 **Fatto!** Entro 30-60 secondi la pagina web ufficiale si aggiornerà automaticamente con le tue modifiche.

---

### Metodo 2: Modalità Editor Avanzata (Con anteprima affiancata)

Se devi fare modifiche estese e vuoi vedere come apparirà la pagina mentre scrivi:

1. Apri la pagina principale del repository su GitHub.
2. Premi il tasto punto (`.`) sulla tastiera (oppure premi `Shift + ?` per vedere le scorciatoie).
3. Si aprirà l'editor di testo completo direttamente all'interno del browser.
4. Clicca sull'icona dell'anteprima in alto a destra (**Open Preview**) per vedere il testo formattato in tempo reale al fianco del tuo codice.
5. Quando hai finito, vai nella barra laterale sinistra sulla scheda **Source Control** (l'icona con i 3 pallini collegati), scrivi un breve titolo spiegando cosa hai cambiato e clicca sul pulsante di conferma (**Commit & Push**).

## 🐛 Bug, Dubbi o Proposte di Emendamento?

Se vuoi sollevare un dubbio sulle regole, segnalare un'incongruenza o proporre una nuova norma senza toccare direttamente il testo:

1. Vai nella scheda **[Issues](../../issues)** in alto nel menu del repository.
2. Clicca sul pulsante verde **New issue**.
3. Inserisci un titolo chiaro (es. *"Chiarimento: Durata degli effetti durante la Torre"*) e spiega la tua proposta o il bug riscontrato.
4. Tutta la comunità dei costituenti potrà discutere nei commenti prima di approvare una eventuale modifica al testo principale.
